# Next identity-root slice: embedded Mach-O N_FUN witness

Source reconciliation only, pinned to `612e1315`. This note owns no implementation or runtime activation. It follows U1's separation of local byte comparison from semantic name binding and U3's requirement for independent supporting roots. Concurrent consumer-refusal source edits were not inspected; direct consumer references below describe the pinned revision.

## Finding

There is a retained independent raw-image name producer beyond PE exports: `corpus/machostabs.py` parses Mach-O `LC_SYMTAB` nlist entries and turns named `N_FUN` records into function names and addresses. Reuse that producer for one narrowly qualified, target-local embedded-STABS lane. Existing source does **not** already suffice for semantic acceptance: the parser/manifest output lacks the strict, immutable-snapshot-bound witness contract that `semantic_identity` and its recorded-name consumers require.

The smallest missing contract is an adapter from a **complete, strictly parsed N_FUN observation of one exact target snapshot and architecture/slice** to a separately scoped recorded semantic witness, plus dispatch of that witness in the existing recorded-name consumers. It is not a new matching engine, cross-build identity promotion, or donor-source distribution contract.

It does not attach a digest or return the captured bytes. Its derived function rows also discard the raw nlist index/string location. Calling it after a separate hashing read is not an immutable-snapshot witness.

These are useful existing attribution contracts, but they do not bind image SHA-256, candidate target-region bytes or semantic acceptance. In particular, `select_slices()` can return multiple same-architecture slices, and the manifest deduplicates identical tuples; neither establishes one unique raw witness row.
- `src/agentdecompile_recovery/targets.py:105` / `identify_binary_snapshot()` at line 110 provide digest and optional retained bytes from one snapshot. `src/agentdecompile_recovery/inventory.py:285` consumes that snapshot and rebinds inventory digest to the bytes actually parsed. - `inventory.py:869` also parses thin Mach-O from a snapshot, and `macho_symbols()` at line 1070 exposes raw `LC_SYMTAB` name/value/type/section metadata, including STABS raw types. This corroborates that there is already a raw symbol metadata source. However, exploratory inventory parsing breaks out of truncated command/table loops, returns a general `complete` status, uses permissive string-table decoding, and infers function sizes from adjacent ordinary symbols. It is not yet a strict semantic witness producer; inferred sizes do not authenticate function extent.

The parser itself also needs a qualification boundary: `MachO._parse_commands()` advances by unvalidated `cmdsize`, `_str()` searches for NUL beyond the declared string table and decodes with replacement, and classic fat enumeration discards declared slice sizes. Reuse the parsing logic under a strict bounded observation, not its current success result as sufficient authority.

## One concrete implementation contract

Proposed scope: `target-macho-stabs-n-fun-name-at-va-v1`, independently recorded from `target-pe-export-name-at-va-v1`. Initially qualify **one thin Mach-O image of the requested architecture**; a thin image has slice offset zero and extent equal to the retained snapshot. Defer fat images until exact slice extent/CPU subtype selection is qualified. This keeps the next slice small without claiming the existing first-slice mapper or architecture-only selection authenticates a fat-image address space.

The producer must use the same retained bytes for SHA-256, header/LC_SYMTAB/STABS parsing and candidate-region comparison. Require corpus digest and candidate target digest to equal that image digest; exact parsed CPU type/subtype, bit width, endianness and slice identity must belong to the selected target. Parse all relevant table extents and names strictly: malformed/truncated tables, out-of-table or unterminated strings, undecodable names and unsupported layout fail closed. Record raw nlist index, record/string offsets, raw `N_FUN` type, declaration, parsed name and n_value VA; source/object strings are attribution context, not extra identity proofs.

For the narrow lane, admit only one nonempty N_FUN name whose parsed name exactly equals the candidate name and whose VA exactly equals its address. Refuse repeated matching-name roots or conflicting named N_FUN roots at that VA rather than silently collapsing them. Refuse missing/unknown selected architecture. Map the candidate's entire positive-size region through one unambiguous file-backed mapping of the selected image; require its recorded offset and machine bytes to agree with that mapping and snapshot. Do not accept the first fat slice, an unchecked first mapping, inferred symbol size or an address-only hit. Preserve the local candidate when semantic admission refuses it.

The recorded reader must recognize the new scope/status/reason and recheck internal equality of target digest/binary/slice/architecture, claim name/VA, witness parsed name/VA and row name/VA. Consumers must describe it as recorded ingestion-time STABS identity, preserving current source freshness gates and separate byte/contribution claims. One independently witnessed candidate remains valid if an unrelated seed or logical-family edge is withdrawn; this lane does not confer that witness on another physical instance.

Required later qualification cases are the independently named positive and Foo-labelled-Bar refusal, name collision/address conflict, malformed symbol/string tables, digest/architecture mismatch, candidate-region mapping mismatch, and refusal of unqualified fat images. No implementation or proof was performed here.
