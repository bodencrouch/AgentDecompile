The synchronous compatibility function remains cooperative; killed-child durability belongs to the new parent-owned path.

No recovery adapter, signer, CAS, configuration, registry, scheduler, outbox or current-reader integration was introduced. A later adapter must map capture-ready to staging and retain the lane/quarantine registry across those paths; the new source does not pretend to implement that adapter.

The entry's exact environment, isolated flags, sealed data documents and fixed hard/soft limits are implemented directly, avoiding the generic sandbox's propagated import/environment state and zero-limit behavior. Those approved costs are preserved rather than hidden in active polling.

The regression definitions meaningfully exercise the actual codec, supervisor, exit and cleanup interfaces through labeled syscall/clock/transport models.
