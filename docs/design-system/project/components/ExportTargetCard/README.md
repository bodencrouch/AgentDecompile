# ExportTargetCard

One deliverable of the export target band, outlined in gate amber.

**Consumer provides** the output name and its three to five body lines.

- `pane`, `gate` stroke at `stroke-export`, `radius-card`; bold `ink-strong` title; `dia-card-try` body.
- The band's promise: "re-run under the same basis → byte-identical bundle". Ambiguous and contested records ship as structured outputs and refuse unsafe use.

**Linking**

- **Publishes:** nothing. Diagram-only.
- **Follows:** nothing; the content is `pipeline-model.json`.
- **Targets rendered:** in app renderings (PipelineMap export band, go-to `~export-readiness`) the title links to its pipeline node (`?node=export-readiness`, `export-lua`, `export-projects`, …); in docs to the outline anchor (`agentdecompile-recovery-pipeline.outline.md#export-readiness`). The EntityBuildCard's export-readiness row links back to `?node=export-readiness`.
- **Absent copy:** none in the diagram. A deliverable with no export receipt in the app says "not exported", never a date.

**Accessibility**

- Each card is a list item with a heading; the amber frame is decorative, the title says what it is. In the SVG each card is a `<g id="export-…">`.
