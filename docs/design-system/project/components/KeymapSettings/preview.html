Character key shortcuts (WCAG 2.1.4)

Global commands always carry a modifier or are function keys. Single keys act only in their scope: a focused list, grid, tree or listbox (composite), a code well (code), or one region. They never fire in text fields or in edit mode. The Off profile turns every single-character key off while modifier globals and menus remain, and any key can be remapped here. Keys only navigate or arm; no key posts or admits work.

Esc order · from keymap.json escapeOrder · innermost layer first
  1. the topmost modal (palette, go-to list, ConfirmDialog, a full-height sheet), focus back to its invoker
  2. the which-key hint, open Peek, sheet or menu
  3. edit mode, restoring the text
  4. the armed ActionStrip, only when focus is inside it; fields kept as a draft
  5. a transient extent such as a byte range, collapsed to the cursor
  6. a transient filter typed in this view
  7. in a secondary or held pane, focus back to the primary pane

Never: the checked set, held panes, kept cards, drafts, or Back.

Conflicts and AltGr

Two commands bound to the same key in the same scope do nothing until the conflict is resolved; the status line says which binding is blocked and why. Ctrl+Alt combinations type characters on AltGr keyboards, so the editor warns when a remap uses one.
