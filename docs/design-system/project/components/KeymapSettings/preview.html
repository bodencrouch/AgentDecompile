Character key shortcuts (WCAG 2.1.4)

Single-key bindings act only while focus is inside a list, grid or listing. They never fire in text fields, on the page body or while a screen reader's browse mode is plausible. Each one can be turned off here or remapped to include Ctrl, Alt or Cmd. Global commands always use a modifier or a function key.
