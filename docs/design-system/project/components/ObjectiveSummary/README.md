# ObjectiveSummary

The top of every objective: accepted capabilities, active attempts, independent eligible work, unmet required predicates and the next automatic action.

**Consumer provides** those five fields from the shared projection that also drives the other surface, the CLI and agents.

- The same five fields in the same order everywhere. Diagnosis expands in place; nobody should correlate logs to learn whether work is progressing.
- The next automatic action is a sentence with its wake condition. If none exists, say so and name what is needed.
