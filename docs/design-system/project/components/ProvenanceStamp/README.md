# ProvenanceStamp

Where a figure or artifact came from and how fresh it is: reused or fresh, current or historical, measured or estimated, with basis and age.

**Consumer provides** the evidence origin (fresh, reused, historical, legacy), measured vs estimate, the basis digest and the observation time.

- Fresh uses an `accent` frame; reused a plain frame; historical a dashed frame; estimate a dotted frame. Digests and times in `type-code-small`.
- Label reused evidence as reused. Never backfill a fresh-run claim. A historical receipt is not fresh progress.
- Every figure shown in a pane carries a stamp or sits under one.
