Consequence

Set DF = 0x1 over 0041b210–0041b24f (64 bytes) on build-a. DF is a flag, not a context register: the next decompile of that range on build-a treats it as the constant 1, and disassembly is unchanged. A context register would also change how the range disassembles; existing instructions are never re-disassembled here, and re-disassembly requires admission as a job. Other builds are unchanged.
