# SplitCompare

Two panes side by side inside the Code Browser, or up to three in the Compare workspace, for the same logical entity on different builds, or for target and rebuilt output. Panes align on recorded anchors only, with scroll lock, difference stepping (F7 / Shift+F7), collapsed unchanged regions and an accessible text diff.

**Use it** for the one secondary pane of the Code Browser and for the Compare workspace's N-way view. **Ctrl/Cmd+\\** opens a **derived** pane on the next build with a counterpart. **Shift+Enter** (Open beside) on a counterpart, address or symbol, from a CounterpartStrip cell, a Peek, a References row or a ReviewDetail, opens a **Held** pane (35). It replaces "switch the inspected build, read, press Back".

**Consumer provides** the primary location (project, logical entity, inspected build, address) and the split pair (`cmp=build-a..build-c`). Per pane: the concrete build and address, or the absence with its locator status and ladder outcome; rows already cached from existing analysis or the stored listing, decompile or bytes; and its ProvenanceStamp (reused, fresh or historical, generation, read time). Per pair: the divergence class, relation kind and components, the IdentityEdge state with its channels and margin, the recorded anchor row pairs with their evidence channel (the same anchor read the CounterpartStrip uses for position mapping), and the difference hunks. For target vs rebuilt: the object pair, the variant (C+floor or max-C), the Local match fact and the comparison receipt.

- **One selection owner.** The first pane is the primary pane ("build-a · primary", "Follows selection"). Every other pane is **derived** ("Counterpart of #88 · derived · via anchors", recomputed from the selection's logical entity on its own build) or **Held** (HeldPane: the always-visible `HELD` tag, "Held · ResourceRef::Resolve @ build-c · 4 min" and "Held · read 13:54" in a 2px `ink-strong` frame, with Make primary, Follow again and Release). Each secondary pane's header has **Hold this pane** (`aria-pressed`, a constant name); Follow again turns a held pane into a derived one.
- **A derived pane never changes its build by itself.** It changes build only through its build menu (which lists only builds with a recorded counterpart; absent builds are words) or Alt+PageDown/PageUp while focus is in it. A held pane never changes at all until Refresh, Follow again or Release.
- **Enter per pane kind.** In the primary pane and in a derived pane, Enter on a link is Go: the one selection moves to that target on that build, stated in the link's description before activation and announced after ("Inspected build: build-c"). In a held pane, Enter moves that pane (HeldPane); **Make primary** is the only promotion. It moves the one selection to the held location, pushes a stop and releases the hold; the pane stays open and becomes Following.
- **Opening a split never changes the primary selection or its inspected build.** The footer says so. Close split returns to one pane and puts focus in the primary pane. Opening or closing a split pushes one history stop (`cmp`).
- **Position mapping uses recorded anchors only.** On an anchor, the other pane lands on its partner. Between anchors it marks the nearest preceding anchor's partner and says "nearest anchor above 0041b213; rows between anchors are not paired". It never interpolates by offset or order. The announcement names the channel and edge state ("rare ref; identity edge candidate"). With no anchors: "No instruction mapping for build-c; showing function start". Rows between anchors are shown in order, and the order claims nothing.
- **Never implies equivalence.** The header always shows the divergence class as framed notation plus words: `1↔1` structural match, `1↔N` split-or-inlined candidate, `≠` diverged (dashed frame). Beside it: the relation kind, the component count and the IdentityEdge state as line style plus word (accepted or candidate), with its channels and margin, and "aligned ≠ equivalent". A held pane on another entity is not aligned, and the header says "no correspondence is drawn". A candidate edge says "candidate" in the pane header, the announcement and the build menu.
- **Review pair header.** When the pair comes from review (ReviewDetail, MatchReview `o`), the header names the candidate edge, never "counterpart": "Review pair · match 18421 · candidate edge", the divergence notation, "candidate ≠ acceptance · aligned ≠ equivalent", and the edge state as of the hold with its read time.
- **An absent counterpart is a pane, not a blank.** It keeps the build header with the word "absent" and its LocatorGlyph in a dashed `line-control` frame on `chassis`, the reason ("diverged — counterpart structurally different, possibly inlined/split"), the ladder outcome with members tried and a link to the ladder evidence. For a build switch it says "build-d: no counterpart (unresolved); staying on build-a" and offers **Open build-d**, which opens build-d's Functions list and carries no address. Nothing is aligned or inferred.
- **Contested in the Code Browser** is one contested secondary pane that lists both evidenced addresses as candidate links, "contested · no winner", with **Compare candidates** and "Open ladder run". Opening a candidate does not accept it. Two held panes ("candidate 1 of 2 · contested · no winner") exist only in the Compare workspace, through Compare candidates. Ambiguous works the same way with its candidates.
- **Read-only by construction.** Panes read cached listings, stored listings and receipts. A pane whose program is not open says "○ Not loaded. Open to read it." with an explicit Open. A project other than the open one lands on the cross-project StateNotice (Switch armed and confirm-gated, Stay). A split never analyzes, imports, compiles, matches or admits work.
- **Rows.** Each pane is a `code-bg` well with `shadow-inset` and `type-code` on fixed 18px lines, so rows stay level across panes. Addresses use `address`, mnemonics `ink-strong`, symbols `lane-identity-ink`. The marker column pairs a glyph with a word (spoken, and in the legend): `↔` anchor (`lane-identity-ink`; the matched token gets a solid 2px `lane-identity-ink` underline), `±` differs (`fact-stale`; the differing token gets a wavy `fact-stale` underline), `−` only on the left build and `+` only on the right build (`ink-strong`), and a hatched `line` filler for "no line on this side". Differing and one-sided rows sit on `raised`. There is no red or green, because neither build is right or wrong.
- **Current difference.** The current hunk has a 2px `ink-strong` outline in every pane, and the toolbar says "difference 2 of 5". The caret line in the focused pane takes the selection shape (`selection` plus a 3px `accent` bar). The mapped anchor row in the other panes takes a 3px `line-control` bar and the words above.
- **Collapsed unchanged regions** are one 26px row per pane, "▸ 9 unchanged lines · 0041b220–0041b23e · Expand", in a dashed `line-control` box on `pane`. Expanding one region expands its partners in every pane. Collapse unchanged is a toggle with `aria-pressed`.
- **Split components** (1↔N) are separated by a labelled rule row in every pane ("component 2 of 2, split part · 00083120").
- **Scroll lock** ("Scroll lock · on anchors", `aria-pressed`) scrolls every pane together and keeps anchor rows level. When it is off, each pane scrolls on its own and anchors stay marked. It is disabled when nothing is aligned.
- **Text diff** (`aria-pressed`) replaces the panes with one ordered list. Each item begins with its word (anchor, same, differs, only on build-a, only on build-c, unchanged) and gives both lines with their build names. It wraps instead of scrolling.
- **Views.** Listing, Decompile and Bytes share one alignment and one difference count (`views`). A view that is not already cached shows Not loaded; it is never computed on open.
- **Target vs rebuilt** uses the same frame with "target" and "rebuilt" in place of build names, plus the object pair, the variant, Local match as a FactBadge and the comparison receipt with its ProvenanceStamp. The header says "local zero ≠ full-image or behavior proof". Relocation-aware equality is written on the row where it applies.
- **Checked set.** A build switch from a pane never carries the checked set: the control's `aria-describedby` says "clears 4 checked rows on build-a" before activation and the polite region confirms after. There is no ConfirmDialog.
- **Stale responses never land.** Each pane's read carries the selection generation. After a 200ms settle, a derived pane keeps its previous rows dimmed with "Loading counterpart of ‹name›" and drops late responses for superseded selections.
- **Layout.** The Code Browser has at most two center panes; the third column exists only in the Compare workspace. Pane headers align across panes (CSS subgrid). Below 2 × `split-min-w` (720px) of component width, one pane shows at a time behind an APG tablist. Its tabs are named "build-a · primary" and either "Held · build-c · 4 min" or "Counterpart of #88 · derived". A derived tab keeps its mapped cursor; a Held tab is frozen. F7 still steps, and it switches the shown tab when a difference exists only on the other side. Below 700px Open beside is the second segment of the split toggle (35).
- **Both surfaces.** The static 8080 surface draws the same header, markers, legend and text diff, and may place the split as a second page region or open Open beside as a new window ("Open beside (new window)"). The full workspace adds subgrid alignment and scroll lock. Both use the same reads and the same URL.

**Linking**

- **Publishes:** inside the Code Browser, `cmp=build-a..build-c`, `views` and `hold` for held panes (`kind:id@build[:addr][~basis]`, at most two); `ws` stays `code`. The Compare workspace publishes `ws=compare` with the same parameters. Opening and closing a split push one stop; stepping differences, Hold, Release and Follow again use replaceState.
- **Follows:** the primary location (`project`, `entity`, `build`, `addr`) after the settle; derived panes resolve the entity on their own build through recorded edges and anchors. Held panes ignore location changes. Each secondary pane is holdable with Hold this pane.
- **Targets rendered:** addresses and symbols in every pane (the Code Browser for that build, with the edge word on counterpart links) · the logical id (Compare with the CounterpartMatrix) · the identity edge (IdentityEdge evidence) · receipt and basis ids (receipt card, ProvenanceStamp detail) · the ladder (evidence rail for that entity and build) · candidate addresses marked "no winner". The link menu is the one flat menu of 35 (Open · Open beside · Peek; Reveal in; Copy).
- **Peek source:** the peek cache and the stored anchor pairs for this entity; a counterpart Peek is anchor-only with "aligned ≠ equivalent" and says "Not loaded. Open to read it." for an unopened program. Nothing is matched or decompiled.
- **Absent copy:** "absent" with its locator word and reason (never a link to a guessed address) · "build-d: no counterpart (unresolved); staying on build-a" · "contested · no winner" · "nearest anchor above 0041b213; rows between anchors are not paired" · "No instruction mapping for build-c; showing function start" · "Not loaded. Open to read it."
- **Target-size exception:** none; toolbar and header controls are 24px, 44px below 700px; code-row links use the code-well inline exception.

**Keyboard**

- **F7 / Shift+F7**: next and previous difference across all panes. Focus moves to the first line of that difference in the focused pane, and "Difference 2 of 9: 0041b240 differs" is announced once. The keys work while focus is anywhere in the split. Suppressing the browser's caret-browsing default for F7 has not been verified per browser; the toolbar buttons and the palette's "Next difference" are the other paths, and the keys can be remapped.
- **Tab order**: header links, then the toolbar (one tab stop; ←/→ between controls; APG Toolbar), then each pane's grid from left to right (one tab stop each). F6 treats the whole split as part of the center region.
- **In a pane grid**: ↑/↓ move by line, PageUp/PageDown by screen, Home/End to the row start and end, Ctrl+Home/Ctrl+End to the first and last line. With scroll lock on, the mapped anchor row in the other panes follows. Enter or Space on a collapsed region expands it in every pane.
- **Links in a pane** use the shared grammar: Enter as described per pane kind; Shift+Enter opens that target beside as a Held pane (within the limit of two; a further one becomes a kept card with its notice); Alt+↓ peeks; Ctrl/Cmd+Enter opens a browser tab; Shift+F10 opens the one link menu.
- **Ctrl/Cmd+\\** (`split.open`) opens a derived pane for the current selection on the next build with a counterpart. **Ctrl/Cmd+Shift+\\** (`split.swap`) swaps pane positions; the primary pane still follows. `g then 2` is the Compare layout preset.
- **Alt+PageDown / Alt+PageUp** (`build.next`, `build.prev`): with focus in a derived pane, they move that pane to the next or previous build with a single-address counterpart (resolved, pinned or degraded) and an accepted or candidate edge, skipping absent, unresolved, ambiguous and contested builds and announcing them by state. In the primary pane they switch the inspected build, stated before and announced after.
- **Alt+F2** (Accessible View; also the palette, Help menu and pane-header button) opens the text diff of the current split.
- **Esc** follows the one order in `keymap.json` `escapeOrder`: from a secondary or held pane it returns focus to the primary pane. Close split is a button, never Esc, so Esc cannot discard a comparison or release a held pane.

**Accessibility**

- The split is a `section` named by its title. Each pane is a `section` named by its build and kind ("Listing, build-c, counterpart of ResourceRef::Resolve, derived"). Each pane's rows form a `role="grid"` with `aria-rowcount`; a held grid's name says "held, as read 13:54".
- Marker glyphs are `aria-hidden`. Every row begins with an `sr-only` word (same, differs, "anchor, rare ref", only on build-a, no line on build-c), and differing tokens are prefixed "differs:".
- The current difference is a `rowgroup` labelled "Difference 2 of 5, current", and the caret line has `aria-current="true"`. Each step is announced once in the polite region. Nothing is announced on scroll.
- Divergence notation is framed text with its words beside it. The identity edge is a line style plus a word. Color is never the only carrier.
- Toggles use `aria-pressed` with constant names. Collapsed regions are buttons with `aria-expanded`. The narrow pane switcher is an APG tablist.
- Text diff is the primary accessible form: one ordered list with explicit words that reflows to 320px without horizontal scrolling (WCAG 1.4.10). Code panes scroll sideways only inside their own well.
- WCAG 3.2.1 and 3.2.2: focus, arrows and difference stepping never switch the build or move the selection. Hold, Release, Follow again and Make primary act only when activated. WCAG 2.4.11: `scroll-padding-block` keeps the current difference clear of the sticky pane header. WCAG 2.5.7: nothing needs dragging; pane widths are set by the splitter keys and the pane-header size menu.

**Removes switching** (the plan ledger is authoritative):

- J01 inspect a function on build A, see its counterparts on B–D, and return: 5 → 1 at ≥700px (2 below), credited to U175 with the CounterpartStrip; Ctrl/Cmd+\\ shows B beside A and Alt+PageDown in the derived pane walks C and D.
- J26 switch the inspected build and keep the entity: 3 → 1 (U175); the position is kept where anchors exist, otherwise the function start is stated.
- J39 iterate on a source repair: 4 → 1, credited to typed links (U171); target vs rebuilt with F7 is one of its steps.

**Parity extensions (2026-09-29)** ([spec](../../../../dashboard-design/2026-09-29-ghidra-code-browser-parity.md): X02, X04)

- A program-level range diff mode (X02). It is aligned by anchors, never raw addresses. Categories: bytes, code units, references, comments, symbols, functions, bookmarks, properties and context. It needs a catalog read action.
- A difference-detail Peek at a location (X04).
- Apply or ignore stays PropagationTransfer's job (X03).
