# Native decompiler replay differential

The native SDK is a replay tier, not an alternative program importer. A Java
Ghidra export creates one `DecompileDebug` savefile plus a Java C oracle for
each function. The native console or `gnsdk-batch` restores only those files.

The first checked-in x86-64 fixture was generated by the exporter from
`tests/fixtures/test_x86_64`. Its `_add`, `_multiply`, and `entry` functions
all classified as exact `match` when replayed with the compiled Ghidra 12.1.3
native console and with `gnsdk-batch`.

Comparison is deliberately narrow: normalize CRLF and trailing whitespace;
retain every other token and layout difference. A non-match is evidence about
the engine or snapshot and must be reported, not normalized away. This keeps
the Java oracle as the authority while allowing JVM-free replay consumers.
