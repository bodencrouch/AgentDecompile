## Qualified scope

Standalone placement, watch and the bulk compiler hook share captured-source
candidate admission. The first provider supports a declared native PE constant-leaf
subset: signed int32 return, no arguments, calls or memory effects, with separately
checked donor/recipient machine behavior and declared ABI facts. Genuine compiler
observations remain process-local authority; serialized receipt JSON cannot recreate
them. Logical identity or an old address-only receipt does not authorize reuse.

Publication creates an immutable, recipient-specific candidate with provenance.
It preserves accepted recipient C and assembly floors and does not count as source
acceptance or recovery. Unsupported broader sources retain explicit unadmitted
proposals. Relevant corpus predicates come from a bounded coherent read snapshot
closed before compilation/wait; the compiler's independent source/image proof is
not mislabeled as database-backed compilation. Watch owns candidate output without
reserving the database for its whole lifetime, allowing matching work to proceed.

Source-address-local queries prevent unrelated links from exhausting a candidate's
snapshot budget. Attempt reservations cover allocation, source writing, compilation
and postcompile failures. Cached authority binds database origin and output scope;
retained candidate evidence and live producer observations are revalidated.
