# Starter prompts

One prompt per phase of the [recovery loop](../RECOVERY_LOOP.md). Paste them as written
or say the same thing in your own words; each one tells the agent which tier it may use
and which claim it may make.

| File | Phase |
|---|---|
| [triage.md](triage.md) | Ingest and provenance, Tier 0 and 1 only |
| [corpus-match.md](corpus-match.md) | Register builds, identify the donor, layered matching |
| [recover-function.md](recover-function.md) | One function to verified C or a labeled `.S` floor |
| [verify.md](verify.md) | Re-check a claim; run the validation gate by hand |
| [export.md](export.md) | Source bundle, hookpack, WASM and Lua exports |
| [insufficient-evidence.md](insufficient-evidence.md) | Force a contested question to a recorded "insufficient" instead of a guess |
