## Conflict decisions that must appear explicitly

1. **Newest summary does not erase earlier comprehensive scope.** September27 weekend-scope explicitly preserves all September18–21 designs and later refinements. Filename date is not precedence by itself; explicit adopted corrections control. No separate September18/19 source was recovered; that is provenance uncertainty, not permission to omit the weekend ambition.
2. **Latest user request is planning-only.** Historical build authorization and lifted test guards remain source history. This turn must not operate 8080, build/test, install, launch ports, change product source or publish. Future implementation validation is specified, not executed.
3. **Two real frontends, one backend state/capability contract.** STRATEGY's heading 'One operator surface (8080)' is operational-catalog policy, not abolition of static `/dashboard`, full Vite application or packaged `/react/`. Current AGENTS and frontend intent explicitly retain both alternatives.
4. **No Start/per-stage Run controls.** Explicit project open/add/resume admits eligible missing work; browsing is read-only. Pause/resume plus scoped stop semantics must follow current frontends contract. Expert verbs remain catalogued and carry mutating/identity-scope/long-running admission metadata.
5. **Runtime observations are claims, not identity.** Separate `runtime_claim` lifecycle; promote only through independent binding, preserve observation axis separately. No runtime-feedback write to identity merely because a locator resolved.
6. **Six locator/readiness statuses are not a readiness ladder.** U30 owns contested/unresolved/ambiguous/pinned/degraded/resolved semantics. Contested precedence is justified by contradictory verified members; a non-discriminating member does not veto a valid first verified ordered member. `observed_status` is separate. Runtime callable/detourable/writable/readable capabilities and source parity are independent axes.
7. **Original-code capability can precede reconstructed source.** Presence, independent semantic identity, operation-specific ABI/layout/lifetime/ownership/policy suffice for the requested original-code operation; whole-image recovery is not a universal runtime prerequisite. Conversely successful original-code use is no recovered-source credit.
8. **Broad program still requires recovered source.** Audit2's optional source row/not-in-scope receipt applies narrowly to the portable export bundle revision, not to STRATEGY's terminal whole-image source mission. Preserve a separately qualified recovered project output and two source variants.
9. **Grid architecture is required now; fleet expansion follows qualification.** Do not classify all Phase15 as optional future scale. Local immutable publish→work→verify→materialize is foundational; increase remote concurrency only after qualified local lanes. No grid completeness gate on safe unrelated local work.
10. **Capability proven by canary governs worker lanes.** Audit4 removed licensing/role-gated object eligibility from this program design; object tags are mirror classes. Roles still control invite signing, verification and applying authority. This does not waive current external publication authority or factual privacy/security requirements.
11. **Generic core and target evidence coexist.** U21's product-name purge is a generic-core/configuration concern reconciled with later governing source documents that intentionally retain named BioWare fixtures and multiplayer research. Do not destroy provenance or rewrite user quotations just to reduce token counts. Keep engine-specific data/adapters separated from portable defaults.
12. **Deadlines and analysis checkpoints.** Older U65 'effectively unbounded' analyzer lifetime cannot override later mandatory declared progress/deadline/containment contracts. Permit long legitimate analysis through checkpointed bounded lifecycle, not infinite unattended hang.
13. **Same-input determinism includes ingest ordering.** Hash/content identities and total sort orders supersede row IDs/slugs. Store-derived nonempty per-binary basis required; NULL/mixed basis refuses mutation/export as applicable. Explicit versioned rebaseline keeps history and invalidates affected descendants.
14. **'One-shot' does not imply unsafe forced success.** Ambiguous/contested/absent/unsupported/budget-exhausted output is durable, evidence-bearing and independently useful; it cannot wait indefinitely for manual review nor bypass runtime refusal. Unknown external effects require reconciliation. Genuine missing credentials/devices remain bounded exceptions.
15. **WASM routes remain distinct.** Browser donated compute and whole-game browser M7 are different. A utility/WASM exporter or browser shell cannot close M7. Any standalone export WASM target lacking a adopted target contract needs an explicit scope-resolution task instead of speculative success.
